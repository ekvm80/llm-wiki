# 감쇠용으로 설계된 구조용 복합재 (리뷰)

## Summary

구조 재료 자체의 복합재 공학(composite engineering)으로 진동 감쇠 능력을 높이되 강성(storage modulus) 저하는 최소화하는 테일러링 전략을 총망라한 리뷰. 감쇠의 원천을 점탄성뿐 아니라 전위·입계·계면 등 결함의 미끄러짐으로 확장하고, 계면적을 키우는 작은 충전제·표면처리가 핵심 수단임을 제시한다. 시멘트계에서는 실리카퓸이 감쇠와 강성을 동시에 크게 증가시키고(모르타르에서 특히 효과적), 철근은 감쇠·강성 모두에 지배적으로 기여하며 샌드블라스팅 표면처리로 추가 향상된다. 연속 탄소섬유 고분자 복합재에서는 점탄성 인터레이어보다 0.1 μm 탄소 필라멘트 삽입층이 50 °C 이상에서 손실모듈러스 면에서 우수하다.

## Key Contributions

1. **감쇠 테일러링의 통합 프레임**: 손실계수(tan δ)↑와 저장계수(E')↑의 곱인 손실모듈러스를 진동저감 성능지표로 삼고, (i) 계면(섬유 코팅·표면처리, 층간 첨가제), (ii) 매트릭스(폴리머 블렌드, 시멘트계 혼화재), (iii) 보강섬유(폴리머 섬유·삽층 흑연섬유), (iv) 추가 섬유(폴리머·피복·형상기억합금 섬유 하이브리드)의 4축 전략을 정리. 점탄성 또는 작은 입자 크기를 가진 첨가제가 유리 — 작은 입자는 계면적을 극대화해 진동 중 계면 미끄러짐 에너지 소산을 키움.
2. **시멘트계 정량 벤치마크(3점 휨, 상온)**: 플레인 시멘트 페이스트 tan δ 0.035(0.2 Hz)·E' 1.9 GPa → 실리카퓸(약 0.1 μm, 15 mass %) 무처리 첨가로 tan δ 0.082·E' 12.7 GPa, 실레인 처리품은 0.087·16.8 GPa — 감쇠와 강성의 동시 대폭 향상. 모르타르(플레인 E' 20~26 GPa)에 처리 실리카퓸 첨가 시 E' 32~33 GPa로 모래 존재 하에서 실리카퓸 효과가 더 큼.
3. **섬유는 무효, 철근은 지배적**: 0.5 vol % 탄소섬유(15 μm, 약 5 mm)·탄소 필라멘트(0.1 μm, 100 μm 초과)·강섬유(8 μm, 6 mm) 첨가는 페이스트 감쇠에 무효~미미(시멘트 페이스트 자체 불균질성의 감쇠가 이미 커서), 강섬유(0.5~1.0 vol %)는 오히려 tan δ 0.046~0.051로 저하 — 섬유 연성보다 계면적이 우위. 반면 강재 철근은 모르타르 tan δ를 0.001 미만 → 0.027(0.2 Hz), E' 20 → 44 GPa로 끌어올리고, 샌드블라스팅하면 tan δ 0.037·E' 46 GPa(1 Hz 기준 0.012·49 GPa)까지 추가 향상 — 표면 변형무늬(리브)와 거칠기의 역할 입증.
4. **실레인 표면처리의 이중 작용**: 실리카퓸 친수화로 수계 시멘트 믹스에서 습윤·분산 개선. 퓸에 적용하면 tan δ·E' 동시 향상, 탄소섬유에 적용하면 E'만 향상. 실레인을 혼화재로 직접 혼입하면 코팅법보다 감쇠·압축연성이 낮고 건조수축 증가 — 입자 간 공유결합 네트워크 형성 때문. 라텍스(styrene-butadiene 분산) 혼입은 tan δ 0.142(0.2 Hz)·0.112(1 Hz)로 최고 수준이지만 실리카퓸보다 비싸 실용성 제약.
5. **고분자 복합재 층간 설계(nylon-6 매트릭스 + 연속 탄소섬유 7 μm)**: 점탄성 시트(55 μm) 삽입 시 종방향 tan δ 0.008 → 0.43(0.2 Hz)이지만 E' 127 → 7 GPa로 붕괴. 오존 처리(160 °C 표면산화) 탄소 필라멘트 삽입층은 tan δ 0.09·E' 115 GPa로 강성 보존. 온도 상승 시 점탄성층의 tan δ·손실모듈러스가 20 → 50 °C에서 급감하는 반면 필라멘트층은 완만해 50 °C·100 °C에서는 처리 필라멘트가 손실모듈러스 최고 — 고온 환경용 감쇠 설계의 근거.
6. **감쇠용 매트릭스 선택 기준(1 Hz)**: PTFE tan δ 0.224·E' 1.34 GPa, PMMA 0.100·3.49 GPa가 구조용 후보(에폭시 0.039, PA-66 0.078, 네오프렌 고무는 tan δ 1.12이지만 E' 7.83 MPa로 비구조용). 폴리머 블렌드·상호침투 네트워크의 성분 간 계면도 감쇠 기제로 유망.

## Methods

리뷰 논문. 수집 데이터는 3점 휨 동역학 기계 시험(0.2 Hz·1.0 Hz) 기반으로, 연속섬유 고분자 복합재는 섬유가 굽혀지는 종방향(longitudinal)과 굽혀지지 않는 횡방향(transverse) 구성으로 구분해 계측(종방향이 실제 구조 복합재에 더 가까움). 시멘트계 표의 일부 데이터(탄소 필라멘트·강섬유 행)는 출처가 Chung 그룹 미발표 결과임을 명시([74], [75] 참조). 시멘트 페이스트와 모르타르의 구분(모래 유무), 실리카퓸 15 mass %·탄소섬유 0.5 vol %·강섬유 0.5~1.0 vol % 등 첨가 수준이 표 1에 정리되어 있다.

## Results

시멘트계 대표값(tan δ / E', 0.2 Hz, 상온 3점 휨):

| 재료 | tan δ | E' (GPa) |
|---|---|---|
| 시멘트 페이스트(플레인) | 0.035 | 1.9 |
| 페이스트 + 실리카퓸(15 mass %, 무처리) | 0.082 | 12.7 |
| 페이스트 + 처리 실리카퓸 | 0.087 | 16.8 |
| 페이스트 + 처리 탄소섬유 + 처리 실리카퓸 | 0.083 | 21 |
| 페이스트 + 처리 탄소 필라멘트 + 처리 실리카퓸 | 0.106 | 11.3 |
| 페이스트 + 강섬유 0.5 vol % + 실리카퓸 | 0.051 | 12.9 |
| 페이스트 + 라텍스 | 0.142 | – |
| 모르타르(플레인) | 0.001 미만 | 20 |
| 모르타르 + 처리 실리카퓸 | 0.011 | 32 |
| 모르타르 + 무처리 철근 | 0.027 | 44 |
| 모르타르 + 샌드블라스트 철근 | 0.037 | 46 |
| 모르타르 + 철근 + 처리 실리카퓸 | 0.027 | 47 |

- 모래(샌드)는 감쇠를 크게 낮추지만 건조수축 억제에 필수적이므로 실용 배합에서는 실리카퓸·철근과 병행.
- 고분자 복합재(종방향, 0.2 Hz): 인터레이어 없음 tan δ 0.008·E' 127 GPa → 점탄성 시트 0.43·7 GPa, 무처리 필라멘트 0.007·65 GPa, 처리 필라멘트 0.09·115 GPa. 손실모듈러스는 점탄성 시트 16 GPa(0.2 Hz)·23.5 GPa(1 Hz)로 상온 최고.
- 온도 의존(0.2 Hz, 종방향): 점탄성 인터레이어의 tan δ는 20 → 50 °C에서 급감, 필라멘트 계열은 소폭 감소에 그침. 50 °C·100 °C에서 손실모듈러스 최고는 처리 필라멘트 삽입층 복합재.
