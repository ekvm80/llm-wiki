# 탄소섬유의 시멘트 진동 감소 효과

## Summary

Chung 그룹(SUNY Buffalo)의 짧은 커뮤니케이션 논문(3 pp). isotropic pitch계 탄소섬유(∅15 µm×5 mm, 0.5 wt %)를 시멘트 페이스트에 혼입하고 표면 처리(오존·디크로메이트·실레인)가 동굴곡 특성(tan δ·저장탄성률·손실탄성률)에 미치는 영향을 평가했다. 실레인 처리 시 저장탄성률 최대 +38 % 향상을 확인했으며, 메틸셀룰로오스 첨가로 tan δ +50 % 가능함을 보였다.

## Key Contributions

1. **표면 처리별 감쇠 특성 정량**: 저장탄성률 순위 — 실레인 > 디크로메이트 > 오존 > 무처리. 실레인 처리 시 최대 38 % 증가(실리카퓸 실레인 처리와 시너지). tan δ는 섬유 혼입으로 오히려 감소.
2. **메틸셀룰로오스의 절충 효과**: tan δ 최대 +50 %(감쇠 개선), 저장탄성률 -14 %(강성 저하) — 기능 설계에서 목표에 따라 선택.
3. **실리카퓸 표면 처리의 역할**: 실레인 처리 실리카퓸 사용 시 저장탄성률 전체적으로 증가(as-received 대비) — 계면 결합 강화가 진동 저항에 기여.

## Methods

- 재료: isotropic pitch계 비코팅 탄소섬유(∅15 µm×5 mm, 인장강도 690 MPa·탄성계수 48 GPa·전기저항 3.0×10⁻³ Ω·cm).
- 혼입률: 시멘트 중량비 0.5 wt %.
- 표면 처리 4종: 무처리 / 오존(O₃ 0.6 vol% in O₂, 160 °C 5 min) / K₂Cr₂O₇+H₂SO₄ 용액 침지(60 °C 2 h) / 실레인(Z-6020 아민+Z-6040 에폭시, Dow Corning).
- 실리카퓸: as-received vs 실레인 처리 2종.
- 측정: 동적 굴곡 시험(Dynamic Mechanical Analysis)으로 0.2·1.0·2.0 Hz에서 tan δ·저장탄성률(E′)·손실탄성률(E″) 측정.

## Results

| 조성 | E′ (GPa, 1 Hz) | tan δ (1 Hz) |
|---|---|---|
| A(기준) | 12.14 | <0.002 |
| A+F(섬유만) | 13.75 | <0.002 |
| A+O(오존) | 14.46 | <0.002 |
| A+K(디크로메이트) | 16.15 | <0.002 |
| A+S(실레인) | 17.67 | <0.002 |
| A+S+silane SF | 21.65 | <0.002 |

- 실레인 처리 실리카퓸+실레인 처리 섬유 조합이 최대 저장탄성률 달성.
