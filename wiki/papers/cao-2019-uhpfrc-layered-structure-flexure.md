# 최적화 적층구조 개념으로 강화한 UHPFRC 휨 성능 — 이론 기준식과 이중 적층 보 실험

## Summary

아인트호벤공대 Brouwers·Yu 그룹의 이론+실험 연구. 휨 보의 인장측에만 강섬유를 집중 배치하는 이중 적층 UHPFRC(조골재 혼입형) 개념을 제시했다. 층 탄성계수비 α = E1/E2와 두께비 β = h2/H로 중립축 위치·첫균열 하중·박리 하중을 닫힌형으로 유출하는 결정론적 기준식을 만들고, 이를 근거로 β = 0.4~0.8의 이중 적층 보(100×100×500 mm, 3점 휨 지간 400 mm)를 설계·시험했다. 동일 총 섬유량(환산 Vf 1.2 %) 단일층 대비 상층 0.6 %+하층 1.6 % 배치(U0.6(40)-1.6(60))에서 최대 휨하중 +24 %·휨에너지 +14 %를 달성했고, 섬유 효율(단위 질량당 휨에너지)이 β = 0.6에서 최대가 됨을 보였다.

## Key Contributions

- 적층 보 첫 파괴 단계의 닫힌형 해석 체계: 평형 조건에서 중립축 h0(식 3), 임계 두께비 βc = √α/(1+√α)(식 4), 임계 인장강도비 γc(식 10)로 첫균열이 상층/하층 어디서 시작하는지 판별. 전단 박리 Fd,shear(식 22)·인장 박리 Fd,tension(식 24) 하중식과 "박리 방지 접착강도 조건"(식 25~27)까지 포함 — 응력-변형률 관계 없이 인장강도·탄성계수만으로 계산 가능해 설계 실용성 확보.
- 실험 검증: 계산 첫균열하중과 실험값 오차 <7 %(β = 0.4~1.0). β = 0.4~0.8에서는 박리 없이 항상 하층 균열로 파괴 단계 종료 — 이론 예측과 일치.
- 최대 휨하중의 3단계 거동 발견: β 0~0.4 완만 증가 → β 0.4에서 도약 → β 0.6~1.0 완만. 도약은 브리징 메커니즘이 골재 지배형에서 섬유 지배형으로 전환되는 지점.
- 섬유 효율 eff_f = E/m_f 개념 신설: β = 0.6에서 최대. 휨에너지 E는 β = 0.4·0.6·0.8에서 무섬유 단일층(U0(100)) 대비 각각 약 20배·31배·32배 향상.
- 섬유 재배치 효과 정량화: 동일 총 섬유량에서 U0(40)-2(60) Fmax 30.12 kN(+14 %), U0.6(40)-1.6(60) Fmax 32.79 kN(+24 %) vs U1.2(100). 에너지는 상층 무섬유면 -10 %, 상층 0.6 % 투입 시 +14 % — 피크하중은 하층 섬유가 지배, 에너지는 양층 섬유가 모두 기여.
- 계면의 역할 재해석: 45 min 타설 간격(초기설정 전)만으로 접착강도 최대 9.28 MPa 달성(표면 처리 불요). 계면은 응력집중으로 미세균열 개시원이 되지만 이 다중 미세균열이 파괴 에너지를 소비해 오히려 휨에너지를 높임.
- 균열 진행 관찰: 하층 균열(t ≈ 12 min) → 계면 근처 상층 소균열(t ≈ 13.5 min) → 연결로 매크로균열(t ≈ 16.5 min) → 완전 파괴(t ≈ 35 min)로 단일층보다 훨씬 느린 파괴 진행.

## Methods

- 배합(w/b = 0.20): CEM I 52.5R 588, 미크로실리카 39.2, 석회석분 156.8, 표준사 839.9, 현무암 조골재 2–5 mm 413.2·5–8 mm 232.3 kg/m³(Brouwers 입도설계), 물 157 kg/m³, PCE 고감수제 5.0~17.0 kg/m³(흐름 ~560 mm), 매끈 직선 강섬유(길이 13 mm, 지름 0.2 mm, 인장 2750 MPa) Vf 0~2 %.
- 시험체: 100×100×500 mm 보, 하층 타설 후 45 min 뒤 상층 타설(하층이 초기설정 전일 때 — 변형 방지+강한 부착), 수중 양생 28 d. 3점 휨 지간 400 mm, 0.2 mm/min 변위제어, LVDT 2개, 노치 없음.
- 보 구성: U0(60)-2(40)·U0(40)-2(60)·U0(20)-2(80)(β 효과), U0.6(40)-1.6(60)(최적안), U0(40)-1.2(60)·U0.6(40)-1.2(60)(층별 섬유 효과), 단일층 U0(100)·U1.2(100)·U2(100) 대조.
- 기본물성: 압축 EN 12390-3, 쪼갬인장 EN 12390-6(층간 부착강도도 쪼갬 시험).

## Results

- 기본물성: 압축강도 140~153 MPa(섬유량 영향 미미), 쪼갬인장은 2 % 섬유에서 무섬유 대비 +97.3 %. 0.6%-1.6% 계면 부착강도 9.28 MPa로 최대.
- 첫균열하중: β 0.4→1.0에서 25.67→26.69 kN으로 둔감(이론 예측과 일치, α = 0.8~1 범위).
- Fmax·E: β = 0.6 선정 근거 — Fmax 도약 후 완만 증가 구간 진입+섬유 효율 최대.
- 재배치 비교(Vf 환산 1.2 % 공통): U1.2(100) / U0(40)-2(60) / U0.6(40)-1.6(60)의 Fmax = 약 26.4 / 30.12 / 32.79 kN, E는 -10 %/+14 % 차이.
- 층별 섬유: 하층 1.2→1.6 % 증가 시(상층 0.6 %) Fmax +19 %·E +38 %; 상층 섬유 증가는 E만 비선형 증가.
- 결론: 상층 40 mm·Vf 0.6 % + 하층 60 mm·Vf 1.6 %가 최적. 다층화·동적(충격) 하중 연구를 후속 과제로 제시.
