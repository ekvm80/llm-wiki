# 강섬유 및 마이크로 섬유(Basalt·PVA·PE) 하이브리드 보강이 150 MPa급 초고성능 콘크리트(UHPC)의 직접 인장 거동에 미치는 영향

## Summary

압축강도 150 MPa급 초고성능 콘크리트(UHPC, W/B = 0.20, 지르코니아 실리카퓸 ZSF 혼입)가 지닌 취약한 인장 연신율 한계($\varepsilon_{tu} < 0.7\%$)를 극복하고 섬유 보강 효율을 극대화하기 위해, 매크로 직선 강섬유($d_f = 0.2\ \text{mm}, L_f = 19.5\ \text{mm}$)와 3종의 상이한 마이크로 섬유—**현무암(Basalt, $d_f = 17\ \mu\text{m}$), 폴리비닐알코올(PVA, $d_f = 39\ \mu\text{m}$), 초고분자량 폴리에틸렌(PE, $d_f = 12\ \mu\text{m}$)**—를 $1.0\ \text{vol.\%}$ 강섬유 + $0.5\ \text{vol.\%}$ 마이크로 섬유(총 섬유량 $1.5\ \text{vol.\%}$)로 하이브리드 조합한 4개 배합을 설계하고, 28일 압축강도, 경화 밀도, JSCE 도그본 1축 직접 인장 시험(변위제어 $0.1\ \text{mm/min}$, 표점거리 80 mm), 균열 패턴 및 **인장 성능 효율 지수(Tensile Performance Efficiency Index)**를 정밀 규명한 전남대학교 이방연(Bang Yeon Lee) 교수 연구팀 및 대구대학교 강수태 교수 공동 연구팀의 랜드마크 UHPC 하이브리드 섬유보강 원전 논문. 연구 결과 강섬유 1.5 vol.% 단독 배합(S1.5) 대비 강섬유 1.0 vol.%와 PE 마이크로 섬유 0.5 vol.%를 혼합한 **S1.0-PE0.5 배합은 28일 압축강도 148.5 MPa를 유지하면서도 극한 인장강도가 13 % 증대한 11.1 MPa, 극한 인장 연신율이 39 % 증대한 0.99 %를 발현**하고 뚜렷한 다중 미세균열을 형성하여 최상의 인장 효율 양(+)의 시너지를 입증하였다. 반면 현무암 섬유(S1.0-B0.5)는 강한 화학 결합과 취성으로 인해 조기 파단되며 인장 연신율이 68 % 급감하였고, PVA 섬유는 계면 손상으로 인장강도가 17 % 저하됨을 규명하여, 150 MPa 초고강도 매트릭스에서는 고강도·고유연 PE 마이크로 섬유만이 유효한 다중스케일 가교 시너지를 제공한다는 핵심 설계 원리를 정립하였다.

## Key Contributions

1. **강섬유-PE 마이크로 섬유 하이브리드를 통한 UHPC 인장 성능 39 % 증대 ($0.71\% \rightarrow 0.99\%$)**:
   - 강섬유 1.0 vol.%와 PE 섬유 0.5 vol.%의 조합으로 11.1 MPa 고인장강도와 약 1.0 %의 연신율을 확보하여 단일 강섬유 보강의 연성 한계를 돌파.
2. **현무암·PVA·PE 마이크로 섬유 3종의 하이브리드 거동 메커니즘 정밀 규명**:
   - 현무암 섬유(취성 파단 $\rightarrow$ 연신율 68 % 급감), PVA 섬유(계면 과도 결합 $\rightarrow$ 강도 저하), PE 섬유(미끄러짐 가교 $\rightarrow$ 다중 균열 및 연신율 39 % 증대) 간의 명확한 물성 차이를 입증.
3. **압축강도 보정 인장 성능 효율 지수(Efficiency Index) 모델 창출**:
   - 섬유 치환 시 발생하는 압축강도 변화율을 차감한 순수 인장 효율 함수를 도입하여 PE 섬유 조합만이 모든 인장 지표에서 완전한 양(+)의 시너지를 가짐을 수학적으로 증명.
4. **미세균열-거대균열 2단계 다중 스케일 가교(Multiscale Bridging) 메커니즘 정립**:
   - PE 마이크로 섬유가 초기 미세균열 발생 시 응력을 분산시키고, 이후 매크로 강섬유가 주균열 개구를 억제하는 상호 보완적 2단계 가교 모델을 확립.

## Methods

- **재료 사양 및 UHPC 배합비 (Table 1~4, 중량비)**:
  - 결합재: 보통 포틀랜드 시멘트(OPC Type I) 1.0, 지르코니아 실리카퓸(ZSF, 비표면적 $8.0\ \text{m}^2/\text{g}$, $\text{SiO}_2 > 94\%$) 0.25.
  - 충전재: 미립 실리카 충전재 (Siliceous Filler, 평균입경 $2.2\ \mu\text{m}$, $\text{SiO}_2 > 99\%$) 0.30.
  - 골재: 규사 ($d_{max} \le 0.5\ \text{mm}$) 1.10.
  - 물-결합재비: W/B = 0.20 (폴리카르복실산계 SP 고형분 바인더 대비 1.6 wt.%).
  - 보강 섬유 조합 (총 섬유량 $1.5\ \text{vol.\%}$):
    1. S1.5 (대조군): 직선 강섬유 ($d_f = 0.2\ \text{mm}, L_f = 19.5\ \text{mm}$, 인장강도 2500 MPa) 1.5 vol.%.
    2. S1.0-B0.5: 강섬유 1.0 vol.% + 현무암 섬유 ($d_f = 17\ \mu\text{m}, L_f = 15\ \text{mm}$, 인장강도 1950 MPa) 0.5 vol.%.
    3. S1.0-PVA0.5: 강섬유 1.0 vol.% + PVA 섬유 ($d_f = 39\ \mu\text{m}, L_f = 12\ \text{mm}$, 인장강도 1600 MPa) 0.5 vol.%.
    4. S1.0-PE0.5: 강섬유 1.0 vol.% + PE 섬유 ($d_f = 12\ \mu\text{m}, L_f = 18\ \text{mm}$, 인장강도 3000 MPa) 0.5 vol.%.
- **실험 장비 및 시험 방법 (Figure 1)**:
  - 압축강도 및 밀도: ASTM C109 ($50\ \text{mm}$ 큐브 시편, 28일 수중 양생 $23\pm 3\ ^\circ\text{C}$).
  - 일축 인장 시험: JSCE 도그본 시편 ($330\ \text{mm} \times 30\ \text{mm} \times 30\ \text{mm}$ 단면, 표점거리 80 mm, 서보 시험기 $0.1\ \text{mm/min}$, 듀얼 LVDT).
  - 균열 분석: 광학 현미경 균열 폭 및 수 전수 측정.

### 2. 하이브리드 파괴역학 메커니즘 해석
- **PE 섬유의 슬립 경화 가교 효과**: 고인장강도(3000 MPa)와 높은 유연성을 갖는 PE 섬유가 균열 개구 시 파단되지 않고 서서히 인발되면서 최대 브리징 응력을 유지하여 균열 전파를 지연시키고 다중 균열을 유도.
- **현무암 섬유의 한계**: 현무암 섬유는 초기 균열 강도를 8.20 MPa로 높였으나, 균열 발생 순간의 국소 전단 응력을 견디지 못하고 취성 파단되어 인장 변형 성능이 급감.

- **종합 결론**: 전남대학교 이방연 교수 연구팀의 본 논문은 150 MPa급 UHPC에서 강섬유와 PE 마이크로 섬유의 하이브리드 배합이 인장강도와 연신율을 동시 극대화하는 다중스케일 가교 메커니즘을 규명한 최고 수준의 UHPC 복합재료 랜드마크 원전 논문임.
