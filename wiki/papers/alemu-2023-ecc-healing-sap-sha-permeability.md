# 광물계 치유제와 SAP를 넣은 ECC의 균열 치유 — 개질 투수 시험 평가

## Summary

plain mortar용 투수 시험 셋업을 ECC용으로 개질(주입 구멍 cast-in + 트러스 지그 능동 균열폭 제어, 다균열 ECC용 신규 능동 변형률 제어법)하여, 예하중 변형률·섬유 함량·광물계 치유제(SHA)·슈퍼흡수성 폴리머(SAP)에 따른 균열 치유를 28일간 투수·RF·강성·균열 영상으로 평가한 논문(조선대 김형기 교신저자 + 전남대 이방연 공동 교신저자). 핵심 결론: 치유 성능은 SHA/SAP 첨가보다 섬유 함량이 지배하며, SAP는 조기 봉합에, SHA는 구속 없는 조건의 강성 회복에 기여.

## Key Contributions

1. 다균열 ECC용 능동 변형률 제어법 신규 개발: 하면 핀 + 디지털 캘리퍼스로 변형률을 측정·조정해 목표 예하중 변형률 ±10 % 유지 — plain mortar용 능동 균열폭 제어(Van Mullem 트러스 지그)와 병행해 ECC와 모르타르의 직접 비교 가능화.
2. 예하중 변형률 영향(R1-F1.25): 0.3/1/2/3 %에서 최대균열폭 MCW 각각 0.05~0.1/0.18/0.58/0.80 mm. 2~3 % 변형률에서도 24~48 h 내 치유분율 0.9 도달 — 균열폭 제어 능력 한계를 넘겨도 섬유 가교가 치유능 대부분을 보존.
3. 섬유 함량의 지배성: PE 1.25 %→0.5 % 감소 시 초기 투수량 8~30배 증가, 28일 치유분율은 R1 -64 %/R2 -67 %/SHA15 -73 %/SAP1.0 -84 % 감소. 균열폭을 0.2 mm 미만으로 억제하면 바인더 종류가 치유를 좌우, 그 이상 균열폭에서는 섬유 함량이 좌우.
4. SHA(OPC 클링커:CSA 클링커:무수석고 = 4:1:1) 7.5/15 % 바인더 치환: 연성 저하(MCW 증가·TCL 감소) → 균열 수 감소·폭 증가로 투수 기준 치유는 악화(28일 치유분율 0.66/0.77 vs 기준 R3 1.0). 반면 구속 없는 조건(unrestrained)의 RF·강성 회복은 통제군보다 우수 — 밀도 높은 치유 생성물 + 하중 제거 시 균열 폐쇄 효과.
5. SAP(아크릴아미드/아크릴산나트륨 공중합) 0.5/1.0 %: 연성 무손상, 12~24 h 내 치유분율 +0.2~0.4의 조기 봉합(팽윤 입자의 균열 직접 봉합, 7일 후 격차 ~0.1로 축소). 압축·인장 강도 손실을 고려하면 0.5 %가 최적. 최종 28일 치유분율: SAP0.5-F1.25-S2 0.95, SAP1.0-F1.25-S2·R3-F1.25-S2 1.0, 나머지 기준 2계 0.91(MCW 0.6~0.74 mm에서도 달성).

## Methods

바인더 = 슬래그 시멘트(OPC:GGBS = 1:1 중량; OPC CEM II/B-S·ASTM C595 Type I, GGBS KS F2563 Type 3·ASTM C989 grade 100), 규사(중앙입경 190 μm) + 크럼버 러버(400 μm, R2·SAP 계열에서는 매트릭스 공극 증대 방지 위해 제외), PE:PVA = 25:2 부피비(PE 1.25 % + PVA 0.10 %). SAP 투입 시 SAP 1 g당 물 9.5 g 추가. 프리즘 시편에 Ø5 mm 주입 구멍을 성형 시 스트로로 형성, 3점 휨으로 균열 발생 후 지그 고정. 투수 시험: 정수두 0.5 m, 로드셀(±0.1 g) 2 s 간격 기록, 5 min~28일 총 11회점 측정, 치유분율 = 1 - Q/Qmax. 측정 사이에는 균열부 수침 + 20 °C·RH 60 % 챔버 보관. 보조 시험: dog-bone(33×6×1.3 cm) 인장 재하중, ASTM C215 RF, 강성 회복, 균열 영상(치유분율·상대 균열폭).

## Results

- plain mortar 대비: 2 % 변형률의 무섬유 시편은 단일 균열 1.42 mm로 자기치유 불가. SHA15-F0 모르타르(0.85 mm 균열) 초기 유량 ~700 g/min으로 ECC(F1.25)의 25배 이상, 28일 치유분율 0.1 미만 vs ECC 0.77.
- 섬유 표면에 calcite 결정 침착(XRD 확인, 선행 연구)이 봉합 메커니즘의 핵심 — 섬유가 투수 저감과 치유물질 침착 위치를 동시에 제공.
- 방법론 교차 검증: Liu 2017(인장 균열 평균 47 μm, falling head, PVA 2 %)·Ma 2014(압열 균열 25 μm, 가압식, PVA 2 %)와 치유분율 추세 일치 — 셋업·균열 생성 방식이 달라도 ECC 치유 경향의 재현성 확인. 단, 변형률·균열폭의 정의가 균열 생성 방식마다 다르므로 절대값 비교는 주의 필요.
