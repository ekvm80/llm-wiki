# 기초-ICP 말뚝 접합부의 반복 거동

## Summary

사용자 그룹 논문(전남대 이방연 공저·충남대 김윤용 교신). 내부충전+횡철근 보강 ICP 말뚝과 기초 접합부의 반복가재 거동을 평가하기 위해 PHC 대조 1개·ICP 시험체 2개를 제작해 반복가재시험을 수행했다. ICP 접합부는 연성비·강성 저하 억제·에너지 소산 능력 모두에서 재래 PHC 접합부보다 우수했으며, 횡철근이 중공 본체와 충전 콘크리트 사이 복합작용(composite action)을 강화함을 확인했다.

## Key Contributions

1. **ICP 접합부의 반복거동 개선 정량**: 하중 지지 능력 증가 + 연성비 향상 + 에너지 소산 능력 증대 + 강성 저하 감소 — 반복 하중 하 접합부 성능 전 항목에서 재래 PHC 대비 우수.
2. **횡철근의 균열 제어 메커니즘**: 횡철근이 균열강도 자체에는 영향 없으나 균열폭·균열 간격·사규열 경사와 길이를 감소 — 균열 폭 분산으로 접합부 연성 확보.
3. **변형률 분포로 복합작용 간접 입증**: 횡철근 변형률 분포 해석 결과 본체와 충전 콘크리트가 유효하게 결합됨을 확인 — ICP 복합 작용의 계면 결합력 실증.

## Methods

- 시험체: PHC 대조 1개 + ICP 2개(횡철근 배근+내부충전 콘크리트 충전).
- 가재: 반복 가재시험(cyclic loading test), 접합부 부위에 수평 가재.
- 측정: 하중-변위 이력곡선, 연성비, 강성 저하율, 에너지 소산량.

## Results

- ICP 시험체들이 안정적 이력 응답과 향상된 하중 지지 능력·연성·에너지 소산 능력 확보.
- 균열: 횡철근이 균열폭·간격·사규열 길이 감소.
- 변형률 분포로 본체-충전 콘크리트 복합작용 확인.
