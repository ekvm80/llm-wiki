# 데이터베이스 기반 콘크리트 최적 배합 — 볼록 껍질 유효영역 제약

## Summary

데이터베이스 학습 기반 예측 모델로 콘크리트 최적 배합을 구할 때, 탐색 범위를 각 재료의 최대·최소값 범위가 아니라 데이터베이스의 최소 볼록 집합(convex hull)으로 한정하는 설계 방법론을 제안했다. 유전자 알고리즘(최적화) + 인공신경망(강도 예측) + quickhull(유효영역 평가)의 3요소로 구현하고, 주어진 강도를 만족하는 최저가 배합 문제에 적용해 검증 실험까지 수행했다. 볼록 집합 밖 배합은 예측 강도 대비 실측이 극적으로 무너짐을 실험으로 보여, 데이터 영역 외삽(extrapolation)의 위험을 정량적으로 입증한 논문이다.

## Key Contributions

1. 유효영역(effective region) 개념: 예측 모델의 정확도가 보장되는 데이터베이스 내부 영역만을 탐색 범위로 정의. 새 배합 x에 대해 데이터베이스 단독의 최소 볼록 집합과 {x} 추가 시의 볼록 집합이 동일하면 유효, 아니면 기각. 창(windowing) 방식과 달리 사용자 파라미터 없이 자동 결정됨.
2. 검증 실험으로 외삽 위험 입증: min-max 탐색(CX 계열)은 볼록 집합 탐색(CO 계열)보다 약 16 % 저렴하지만, CX40 실측 강도는 3.81 MPa에 불과(예측 41.1 MPa, 상대오차 978 %) — 물·시멘트량 부족으로 시멘트 풀이 부족했고 슬럼프 시험(KS F 2402)에서 유동성 거의 없음 + 골재분리 발생. CO 계열은 오차 최대 8.13 %로 요구강도 모두 만족.
3. 완결된 구현 사례: ANN(입력 4재료 중량 그대로, 은닉층 1개, 노드 수 교차검증으로 결정 4-4-1, jack-knife 검증 상관계수 R = 0.954) + 실수형 GA(모집단 100, 룰렛 선택 10 %/교차 70 %/돌연변이 20 %, 50세대 무개선 시 종료) + 페널티 함수형 목적함수(가격 최소화, 총부피 ±0.1 % 허용).

## Methods

- 데이터베이스: 일본 New RC 프로젝트 배합 3,000 개 이상 중 선별 179 개. 조건 — 시멘트·물·잔골재·굵은골재 4성분만, 1종 포틀랜드시멘트, 28일 압축강도 측정, 혼화재료 무첨가. 범위: W/C 20.0~70.0 %(평균 40.0), 물 108~225 kg/m^3, 시멘트 252~900, 잔골재 349~1074, 굵은골재 452~1416, 강도 11.0~145 MPa(평균 54.5). 양생 80 % 이상 20 °C 수중양생.
- ANN: 은닉 뉴런 하이퍼볼릭 탄젠트 전달함수, 출력층 선형. 학습은 가중치 감소 항 추가된 Levenberg-Marquardt. 은닉 노드 1~7개 × 10회 교차검증 × 20회 반복으로 4-4-1 선택.
- 볼록 집합: quickhull 알고리즘(Barber et al. 1996).
- 목적함수: fitness = f_cost + f_vol + f_reg + f_str. 단위가격(원/kg) — 물 0, 시멘트 79.2, 잔골재 3.70, 굵은골재 2.83.
- 검증 실험: Ø100 × 200 mm 원주공시체, KS F 2405 압축시험, 각 배합 8본.

## Results

- 실측 강도(예측 대비 상대오차): CO40 = 40.6 MPa(표준편차 0.91, 8.13 %), CO50 = 51.3 MPa(1.93, 6.24 %), CO60 = 61.2 MPa(1.07, 5.39 %) — 모두 요구강도 충족. CX40 = 3.81 MPa(978 %), CX50·CX60은 미실시(동일 원인 판단).
- 결론: 탐색 범위 확장은 가격을 낮추지만 제조 가능성과 강조건 만족을 보장하지 못한다. 데이터베이스 영역 특성 반영이 데이터 기반 배합 설계의 신뢰성 핵심.
- 이 논문은 후속 연구(저자들의 ECC/시멘트계 복합재료 배합 최적화 계열)와 데이터 기반 설계 접근의 토대가 되며, 소규모 데이터베이스로 학습된 예측 모델을 쓰는 모든 배합 최적화 연구에 적용 가능한 일반 원칙을 제시한다.
