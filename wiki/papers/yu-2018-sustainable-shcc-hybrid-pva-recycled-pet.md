## Summary
환경 오염을 유발하는 폐플라스틱 음료병(Recycled PET Bottles)을 업사이클링하여 제조한 재생 PET 섬유(Recycled PET fibers, 직경 35 µm, 길이 12 mm, 인장강도 750 MPa)를 고가의 PVA 섬유와 하이브리드 조합(총 $V_f = 2.0 \%$, PET 0.5 ~ 1.5 vol %)으로 치환한 지속가능 고연성 복합체(Sustainable SHCC)의 단일 섬유 인발 가교 특성, 직접 인장 변형경화 및 미세균열 제어 거동을 동지대학교 위커취안(K.Q. Yu) 교수 연구팀이 규명한 논문이다. PVA 1.0 % + PET 1.0 % 최적 하이브리드 배합에서 28 d 압축강도 **44.5 MPa**, 직접 인장강도 **4.85 MPa**, 극한 인장 변형률능 **4.2 %**를 달성하고 섬유 원가를 **45 %** 절감하였다.

## Key Contributions
- **폐PET 섬유의 고연성 SHCC 적용 미시역학 타당성 세계 최초 입증**: 단일 PET 섬유 인발 시 계면 마찰응력 $\tau_0 = 1.15 MPa$ 확보.
- **PVA-PET 다스케일 하이브리드 가교 시너지 확립**: 친수성 PVA 섬유의 높은 화학 부착력과 소수성 PET 섬유의 안정적 마찰 슬립 결합.
- **원가 45 % 절감 및 인장 변형률능 4.2 % 확보**: 폐기물 재활용과 초고연성 복합체 상용화 동시 달성.
- **다중 미세균열 제어 실증**: 파괴 시까지 평균 균열폭 $35 \mu m$ 이하 유지.

## Methods
- 바인더: 시멘트 30 % + 플라이애시 70 %, $W/B = 0.32$.
- 섬유 조합: PVA 단독(2.0 %), PET 단독(2.0 %), Hybrid (PVA 1.5 % + PET 0.5 %, PVA 1.0 % + PET 1.0 %, PVA 0.5 % + PET 1.5 %).
- 시험: 도그본 직접 인장 시험 ($0.5 mm/min$, DIC 변형률), 단일 섬유 인발 시험, 28 d 압축강도.

## Results
- 섬유 조합별 지속가능 SHCC 28 d 역학 물성 비교표:

| Control-PVA | 2.0 % | 0.0 % | 45.0 | 5.20 | 4.80 | 100 % |

| HYB-P1.5-PET0.5 | 1.5 % | 0.5 % | 45.2 | 5.05 | 4.50 | 80 % |
