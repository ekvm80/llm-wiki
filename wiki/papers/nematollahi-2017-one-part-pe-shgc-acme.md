## Summary
위험하고 부식성이 강한 액상 알칼리 활성화제 취급 문제를 해결하고 일반 시멘트처럼 물만 부어 시공하는 1액형 무시멘트 고연성 지오폴리머 복합체(One-Part PE-SHGC)를 구현하기 위해, 고상 규산나트륨 분말과 수산화나트륨 분말을 건식 결합재에 사전 혼합하고 초고분자량 PE 섬유($V_f = 2.0 \%$)를 보강한 복합체의 상온 양생($23 °C$) 역학 물성, 단일 섬유 인발 가교 특성 및 일축 직접 인장 변형경화 성능을 스윈번 공대(Swinburne University) 네마톨라히(B. Nematollahi) 박사 연구팀이 규명한 연구이다. 상온 28 d 압축강도 38.5 MPa, 직접 인장강도 4.8 MPa, 인장 변형률능 **4.2 %**의 우수한 연성을 달성하였다.

## Key Contributions
- **물만 투입하는 1액형 고연성 지오폴리머(One-Part SHGC) 상온 경화 기술 확립**: 현장 타설 적용성 및 시공 안전성 비약적 향상.
- **고상 활성화제 용해 속도와 PE 섬유 가교력의 정합성 입증**: $J_b'/J_{tip} = 4.5$ 확보로 안정적 다중 미세균열 유도.
- **인장 변형률능 4.2 % 실현**: 상온 양생 조건에서 포틀랜드 시멘트 기반 일반 PVA-ECC를 능가하는 연성 확보.
- **체화 탄소 65 % 감축**: 산업 부산물 플라이애시/슬래그 활용 저탄소 건설 재료 상용화 기반 제공.

## Methods
- 바인더: F급 플라이애시 70 % + GGBS 30 % + 고상 규산나트륨 분말 ($Na_2O 14.7 \%$, $SiO_2 29.4 \%$) + 무수 고상 $NaOH$, $W/B = 0.33$.
- 섬유: Spectra PE 섬유 ($V_f = 2.0 \%$, 직경 38 µm, 길이 12.7 mm, 인장강도 2600 MPa, 탄성계수 75 GPa).
- 시험: 도그본 직접 인장 시험 ($0.5 mm/min$, LVDT 계측), 28 d 압축강도 (50 mm 큐브), 미니슬럼프 플로우.

## Results
- 1액형 PE-SHGC 28 d 역학 특성 데이터:

| 물성 항목 | 액상 활성화제 2액형 EGC | 본 연구 1액형 One-Part SHGC | 비고 |
| :--- | :---: | :---: | :--- |
| 28 d 일축 압축강도 (MPa) | 42.0 | 38.5 | 상온 100 % 강도 발현 |
| 초기 균열 인장강도 (MPa) | 3.2 | 3.1 | 동등 수준 |
| 극한 직접 인장강도 (MPa) | 5.1 | 4.82 | 인장 변형경화 발현 |
| 극한 인장 변형률능 (%) | 4.50 | **4.20** | **4 % 이상 초고연성** |
| 평균 균열폭 (µm) | 35 | 42 | 미세 분산 균열 제어 |
