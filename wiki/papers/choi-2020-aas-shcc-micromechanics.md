# PE 섬유 보강 AAS-SHCC의 미시역학 기반 연성 해석

## Summary

사용자 그룹 논문(전남대 이방연 공저). PE 섬유 보강 알칼리 활성 슬래그(AAS) 복합재의 초고연성 메커니즘을 실험+미시역학 해석으로 규명한 논문. 압축 36.8 MPa(중간 수준)에서 인장강도 8.5 MPa·변형률능 최대 7.5 %·균열폭 59.8 µm의 포화 다중균열을 달성했으며, 매트릭스 파괴인성과 계면 특성 변동을 반영한 이론 브리징 곡선이 실험 인장거동을 잘 재현함을 보였다.

## Key Contributions

1. **AAS-SHCC 초고연성 입증**: 압축 36.8 MPa(중간)에서 인장강도 8.5 MPa·변형률능 7.5 %. 시멘트 대비 CO₂ 배출 ~1/7이라는 지속가능성 장점과 결합한 고연성 실증.
2. **미시역학 파라미터 정밀 측정**: 매트릭스 파괴 인성(K_m), 섬유-매트릭스 계면 특성(부착 강도·마찰)을 직접 계측하고 이를 브리징 곡선 시뮬레이션에 입력.
3. **포화 다중균열 + 균열폭 제어**: 평균 균열폭 59.8 µm로 자기치유 임계(100 µm) 이내 유지 — 내구성 관점에서 AAS-SHCC 적합성 입증.
4. **이론-실험 상호 검증**: 매트릭스 물성·섬유 분산 변동을 고려한 이론 브리징 곡선이 실험 응력-변형률 거동을 재현해 미시역학 설계 접근의 타당성 확인.

## Methods

- 재료: AAS 결합재(GGBS 기반)+PE 섬유.
- 미시역학 계측: 매트릭스 파괴 인성, 섬유 인발 시험으로 계면 부착 특성 산정.
- 복합체 시험: 압축(ASTM C109 계열), 직접인장(dumbbell), 균열 패턴 분석(균열수·폭).
- 해석: 브리징 곡선 σ_B(δ) 시뮬레이션에 매트릭스·계면 파라미터 변동 반영.

## Results

- 압축강도 36.8 MPa / 인장강도 8.5 MPa / 변형률능 최대 7.5 % / 평균 균열폭 59.8 µm(포화 균열).
- 이론 브리징 곡선이 실험 인장 거동 양호하게 재현.
